# HHZ 报价平台 — 主从局域网部署与使用指南

本平台由两个独立的 Windows 程序组成，在同一局域网内工作：

- **主设备（母机）**：`HHZDataService.exe` —— 后台服务 + 管理工作台。负责保存所有设备、耗材、套餐、公司信息与报价参数，并作为「数据源」供客户机同步。
- **客户机（从机）**：`超声医疗报价平台.exe` —— 仅报价页面（交付文件为 `超声医疗报价平台 Setup <版本>.exe` 安装包，装好后主程序同名）。开机自动从主设备同步数据；主设备不在线时用本机缓存或内置演示数据。

数据流向为**单向（主 → 从）**：客户机只读、绝不回写主设备。

---

## 一、主设备（母机）装机

1. **安装并启动**：运行 `HHZDataService Setup <版本>.exe` 安装版（推荐，安装时**自动放行防火墙 TCP 8000**，无需手动操作）；或用绿色版 `HHZDataService.exe`（直接双击即可运行）。右下角出现托盘图标即表示服务已启动。
2. **首次运行**：程序会自动打开浏览器进入工作台页面 `http://127.0.0.1:8000`。第一次进入会要求先注册工作台账号（用户名 + 密码 + 确认密码），注册成功后自动登录。数据库内置应急账号 `admin / admin123` 仅作恢复兜底，不在登录页展示。
3. **防火墙**（安装版在安装时已自动放行，此步可跳过）：若用的是**绿色版**，或安装后客户机仍连不上，以管理员身份执行
   `powershell -ExecutionPolicy Bypass -File scripts\allow-firewall.ps1`（放行 TCP 8000，仅专用网络）。
4. **录入数据**：在工作台依次维护「设备管理 / 耗材管理 / 套餐管理」，并在「基本设置」里填写公司抬头与报价参数。
5. **开机自启**：右键托盘图标 → 勾选「开机自启」。
6. **备份**：右键托盘图标 → 「打开数据目录」复制 `uploads` 照片目录，并用 `pg_dump` 导出 PostgreSQL 数据库（两者合起来即为完整备份）。

> 主设备必须保持开机（服务在托盘运行），客户机才能同步到最新数据。

## 二、客户机（从机）装机

1. 运行 `超声医疗报价平台.exe`（安装版从开始菜单/桌面快捷方式启动），进入报价页面。
2. 首次使用点击右上角「连接主设备」：
   - 点「自动发现主设备」让程序扫描局域网；或
   - 手动填写主设备地址（形如 `http://192.168.1.100:8000`）→「测试连接」→「保存」。
3. 之后每次开机都会自动同步主设备数据。

**离线兜底**：若主设备未开机，客户机会自动使用「上次同步的本地缓存」；从未同步过的新机器则显示内置演示数据，并在顶栏提示「未连接主设备」。

## 三、同步说明

- 同步范围：设备 + 耗材 + 套餐 + 绑定关系 + 公司信息 + 报价参数 + 产品图片。
- 主设备改完数据后，客户机无需重启：点击顶栏「连接主设备」→「立即同步最新目录」即可看到最新数据；
  自动发现/保存主设备地址时也会顺带重新同步。图片为增量同步，不重复下载。
- 客户机上的手动改价、报价草稿仅保存在本机，不影响主设备与其他客户机。

## 四、套餐与 Quote 的对应关系

- **固定整购套餐**：在 Workbench「套餐管理」勾选“固定整购套餐”。一个套餐可以包含任意多台设备/多款耗材
  （多 SKU 模块），Quote 的“套餐整购”模式会直接选择该套餐并输入购买套数，报价单按全部 SKU 模块展开。
  Quote 只在“当前所选设备 + 耗材命中该固定整购套餐”时才显示“套餐整购”；其它组合不会出现妇科等无关
  套餐，仍保持“同时购买 / 仅购耗材 / 仅购设备”三种模式。
- **赠机/推广方案**：不勾选“固定整购套餐”，Workbench 填写设备与适配耗材行。Quote 的“同时购买”模式会
  按当前所选设备 + 耗材自动匹配该方案并计算赠机/套数。
- Workbench 修改套餐或价格后，在 Quote 点「连接主设备」→「立即同步最新目录」，新方案无需重启即可生效。
- Quote 的采购模式按钮不是写死的：Workbench 同步什么设备/耗材/套餐，Quote 就显示对应的
  “同时购买 / 仅购耗材 / 仅购设备 / 套餐整购”组合。

## 五、构建产物（给开发者）

**客户机 exe（报价版 Electron）** —— 可在 macOS 或 Windows 构建：

```bash
# 以下命令在 Quote/ 目录下执行（cd Quote）
# macOS：vite build + electron-builder，复用项目内缓存（不下载 Electron）
ELECTRON_BUILDER_CACHE=$PWD/../.electron-cache \
  npx electron-builder --win --x64 -c.electronDist=$PWD/../.electron-cache

# Windows：直接 npm run build:win（electron-builder 自动下载 Electron）
npm run build:win
```

产物在 `Quote/release/`：`超声医疗报价平台 Setup <版本>.exe`（安装版）+ `…-win.zip`（绿色版）。

**后端 exe（HHZDataService.exe + NSIS 安装版）** —— PyInstaller 不支持跨平台，Windows exe 只能由「Windows Python」产出：

```bat
:: Windows 原生（推荐）：scripts\build-backend.bat 一键完成
:: 前端构建 → 安装后端依赖 → pyinstaller 打包 → 复制到 release\
:: → 生成 NSIS 安装版（release\HHZDataService Setup <版本>.exe）
scripts\build-backend.bat
```

macOS / Linux 上可用 `node scripts/build-backend-exe.mjs` 走 Docker + Wine 容器等效构建
（首次自动拉取约 1.5GB 镜像、Apple Silicon 走 amd64 模拟较慢；需要 Docker Hub 网络可达；
结尾同样自动生成 NSIS 安装版，前提是本机有 makensis，见 `docs/BUILD-AND-DEPLOY.md` §B2）。

完整的「代码直跑 / 打包 exe」双模式命令与数据目录差异，见 `docs/BUILD-AND-DEPLOY.md`。

## 六、常见问题

| 现象 | 排查 |
| --- | --- |
| 客户机提示「未连接主设备」 | 主设备是否开机、是否在同一局域网、是否已放行 8000 端口 |
| 浏览器进不了工作台 | 主设备上访问 `http://127.0.0.1:8000`；局域网内访问 `http://主设备IP:8000` |
| 忘记工作台密码 | 可使用数据库内置应急账号 `admin / admin123` 登录（不对外展示），进入「基本设置」后重新设置正式账号密码；若连内置账号都无法登录，再操作主设备数据库（`users` 表） |
| 换主设备 | 在新机器上恢复 PostgreSQL 数据（`pg_dump` / `pg_restore`），并把旧主设备 `%APPDATA%\QuoteSys\uploads` 照片目录复制过去即可迁移全部数据 |
