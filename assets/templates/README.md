# QuoteSys 模版与静态资源规范 (Assets & Templates)

本目录用于存放 QuoteSys 通用商业报价系统的企业品牌资产、报价单模版以及批量数据导入模版。在将 QuoteSys 部署并交付给特定企业或业务客户时，可通过替换或配置本目录下的模版资源快速完成客制化。

---

## 目录结构规划

```
assets/templates/
├── README.md                     # 模版资源规范说明文档（本文件）
├── logo.png                      # 企业通用商标 / Logo 占位图（建议透明底 PNG 或 SVG）
├── quotation_terms.md            # 默认报价单落款条款、保修约定与交付说明模版
└── product_import_template.xlsx  # 商品目录与阶梯价格批量导入标准样表
```

---

## 模版资源说明与客制化指南

### 1. 企业 Logo / 品牌标识 (`logo.png`)
- **用途**：在客户端报价单打印预览、PDF 导出、报价单顶部抬头及系统登录页展示。
- **推荐规格**：
  - 格式：PNG（支持 Alpha 透明通道）或 SVG
  - 推荐分辨率：`400 x 120` px 或矢量无损缩放
  - 宽高比：约为 3:1 ~ 4:1 横向矩形为佳

### 2. 报价单落款与通用条款模版 (`quotation_terms.md` / 配置项)
- **用途**：用于报价单底部的供货商开户信息、结算条款（如预付款比例、账期）、交付周期承诺、质保政策及签名盖章区域。
- **默认占位信息**：
  - 供货方全称：`[企业名称占位符]`
  - 开户银行与账号：`[开户行与账号占位符]`
  - 默认有效期：报价发出后 15 / 30 个自然日
  - 售后质保：标准整机质保期及响应时限说明

### 3. 商品与阶梯定价导入模版 (`product_import_template.xlsx`)
- **用途**：供工作台（Workbench）后台管理员批量导入新商品目录、技术规格、指导价、底价保护线及阶梯折扣率。
- **标准表头字段**：
  - `商品编码 (SKU)`：唯一字符串编码
  - `商品名称`：标准品名
  - `类别/系列`：多级商品类目（如 `/核心设备/超声主机`）
  - `规格型号`：详细技术规格描述
  - `单位`：台 / 套 / 件 / 箱
  - `成本基准价`：最低限价保护基准（元）
  - `公开指导价`：市场统一标价（元）
  - `阶梯折扣规则`：如 1-4 台无折扣，5-9 台 95 折，10 台以上 90 折
  - `状态`：启用 / 停用

## 注意事项

1. **敏感业务数据隔离**：严禁将包含特定客户商业机密、真实底价成本、客户私人联系方式的实际业务表格提交至代码仓库公共分支。
2. **字符编码**：所有文本与 Markdown 模版必须统一使用 UTF-8 编码，Excel 样表必须兼容 `.xlsx` (Office Open XML) 格式。
3. **资源引用路径**：系统在生成 PDF 或打印渲染时，统一从当前配置的资源路径或静态文件服务器读取。
